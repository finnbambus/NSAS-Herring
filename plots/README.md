The Folder “plots” contains plots generated inside the R code of this
project.

-   **component\_map** show a bathymetric map of the North Sea and the
    area of each component adapted from Payne 2010 & Dickey-Collas et
    al. 2009.
-   **env\_grid** shows a grid of time-series of the environmental data
    (Sea-Surface-Temperature, Sea-Surface-Salinity and prey abundance) of the individual spawning
    components and the full stock. They contain averages for the area mapped in
    “component\_map”. It contains a foreground layer (solid lines) that plots the averages for the autumn season, and a background layer (dashed line) with the yearly average.
-   **hysteresis\_** shows the relationship Spawning-Stock-Biomas (SSB)
    to Fishingmortality (F) pattern of hysteresis for the full stock and
    individual components.
-   **LAI\_by\_year** shows the time-series of the
    Larvae-Abundance-Index (LAI) for each spawning component.
-   **LAI\_percent** shows the percentage of the total LAI each
    component contributes over time.
-   **SRR\_** plots the Stock-Recruitment-Relationship, SSB vs
    Recruitment (R) for the full stock and individual components.
-   **SSB\_cpt\_** shows the SSB for each area over time including
    calculated change-points and corresponding phases.
-   **overview** contains a grid of basic descriptive plots for the stock (SSB, Recruitment, F and recruitment residuals for the most appropriate model)
-   **tGAM** The tGAM folder contains the resulting plots (GCV & SRR) for accepted thresholds
