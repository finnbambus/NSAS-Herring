# Analysis of Regime Shifts in North Sea Atlantic Herring (NSAS)

This project analyzes the North Sea Atlantic Herring (*Clupea Harengus*) stock for regime shifts, inspired by the methods presented in the paper ["Regime shift dynamics, tipping points and the success of fisheries management” by Blöcker et al. 2023](https://www.google.com/search?q=doi.org/10.1038/s41598-022-27104-y). The R code and structure are adapted from the code available on [GitHub](https://github.com/HeleneGutte/tipping_northsea_fish/tree/main).

The project uses data from various sources to explore the dynamics of the herring stock and its components, looking for evidence of hysteresis patterns and abrupt shifts in relation to environmental factors and fishing pressure.

## Folder Structure

The repository is organized into the following directories:

  * **`data raw/`**: Contains all the original, raw data as received from various sources in May/June 2025. This includes environmental data from Copernicus Marine, plankton data from the Continuous Plankton Recorder project, and herring stock data (LAI, SSB) from ICES and the Pelagic Freezer Trawler Association (PFA).
  * **`data/`**: Contains the processed and cleaned data in `.Rdata` format, ready for analysis. These files are generated by the `data_cleanup.Rmd` script.
  * **`R/`**: Contains all the R code used for data processing, analysis, and visualization.
  * **`plots/`**: Contains the plots generated by the R scripts, including maps, time-series, and relationship plots.

## How to Use

1.  **Data Preparation**: Run the `R/data_cleanup.Rmd` script. This will import the raw data from the `data raw` folder, clean it, and save the processed data into the `data` folder as `.Rdata` files. This script also generates initial exploratory plots which are saved in the `plots` folder.
2.  **Data Analysis**: Run the `R/data_analysis.Rmd` and or `R/data_analysis_component.Rmd` script. This scripts load the cleaned data from the `data` folder and perform the regime shift analysis for the full stock and or each component. Both utilize functions defined in `R/functions.R`.

## Code Description

The `R/` directory contains the following key scripts:

  * **`data_cleanup.Rmd`**: Imports and cleans all necessary raw data.
  * **`data_analysis.Rmd`**: Performs the main analysis for regime shifts.
  * **`data_analysis_component.Rmd`**: Performs the main analysis for regime shifts on a component base.
  * **`functions.R`**: Contains various functions used in the cleanup and analysis scripts to avoid clutter.
  * **`model_comp_functions.R`**: Contains functions for comparing and fitting different models as well as perfoming a leave-one-out-cross-validation.
  * **`map_component.Rmd`**: Generates a bathymetric map of the North Sea showing the different herring spawning components.

## Data

### Raw Data (`data raw/`)

The analysis is based on a variety of datasets:

  * **Environmental Data**: Sea Surface Temperature (SST), Sea Bottom Temperature (SBT), and Sea Surface Salinity (SSS) from the Copernicus Marine MyOcean platform.
  * **Plankton Data**: Abundance data from the Continuous Plankton Recorder (CPR) project, provided by the Marine Biological Association.
  * **Herring Data**:
      * Larva Abundance Index (LAI) and Spawning Stock Biomass (SSB) data from ICES and its Herring Assessment Working Group (HAWG).
      * Official stock assessment data (Recruitment, Catch, Fishing Mortality) from the 2024 ICES advice.
  * **Geographical Data**: Shapefiles defining the herring spawning components, adapted from Payne (2010).

### Processed Data (`data/`)

The raw data is processed into several `.Rdata` files for ease of use in the analysis, including:

  * **`env_*`**: Environmental data, subsetted by spawning component.
  * **`LAI_full` & `LAI_aggregated`**: Larval Abundance Index data.
  * **`Herring_LAI` & `Herring_full`**: Herring stock data including SSB, F, and R.
  * **`CPR`**: Plankton data filtered by component.

## Plots

The scripts generate a number of plots, saved in the `plots/` folder, to visualize the data and analysis results:

  * **`component_map`**: A map of the North Sea showing the herring spawning component areas.
  * **`env_grid`**: Time-series of environmental data for each component.
  * **`hysteresis_*`**: Plots showing the relationship between Spawning Stock Biomass (SSB) and Fishing Mortality (F).
  * **`LAI_*`**: Time-series plots of the Larval Abundance Index.
  * **`SRR_*`**: Stock-Recruitment-Relationship plots.
  * **`SSB_cpt_*`**: SSB time-series for each area with identified change-points.
